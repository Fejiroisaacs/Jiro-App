# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request. Use **Report a vulnerability** on this repository's **Security** tab (GitHub's private vulnerability reporting).

Include:

- what you found;
- how to reproduce it: the page or API route, and the steps;
- what it lets someone do.

You should get a reply within a week.

## Scope

**In scope:** the live app at <https://jiro-app-3e88c.web.app>, its API, and the code in this repository.

**Out of scope:**

- denial of service, and anything that relies on flooding requests;
- social engineering, or physical access to someone's device;
- scanner output with no demonstrated impact;
- the demo account refusing changes: it is look-only by design.

## While testing

- Use your own accounts or the demo. Don't access, change or delete other people's data.
- Stop once you have shown the problem, and report it.
- Allow time for a fix before telling anyone else.

## Supported versions

Only the live app and the `main` branch are maintained.
